群里的 AI 资讯简报员。资料来自 AIHOT，Grok 写成中文简报。飞书里搜应用名 AI 资讯。

1. 飞书应用

  1. 打开 飞书开放平台，建企业自建应用，名称填 AI 资讯（拉群时搜这个名字）。
  2. 应用能力 → 机器人 → 打开。
  3. 事件与回调 → 使用长连接接收事件（不要填 webhook）。订阅 im.message.receive_v1。后台服务要先在跑，长连接才能挂上。
  4. 开通下面的权限，创建版本并发布。改权限后必须再发一版。
  5. 到本站 设置 填写应用 ID 和密钥，保存并连接。

2. 权限

开放平台搜中文名或下面的 scope。没发布的权限等于没开。

权限Scope
获取群聊中 @ 机器人的消息 im:message.group_at_msg:readonly 必开
以应用的身份发消息 im:message:send_as_bot 必开
获取群组信息 im:chat:read 必开
获取用户发给机器人的单聊消息 im:message.p2p_msg:readonly 可选
添加消息表情回复 im:message.reactions:write_only 可选

「获取群组信息」开放平台也可能写成 im:chat:readonly。后台列群名、提问人姓名都走这条，不另要通讯录权限。没发版时勾选仍可用，只是看不到名字，错误码常见 99991672。

3. 登录 Grok

到 设置 → Grok 订阅，走官方 device-code，不是 API key。凭据写在本机 data/xai-auth.json，不要和其他项目共用。左边栏 Grok 灯变绿之后，群里才能写出简报。模型默认快模型，点选立刻生效。

4. 拉群并打开开关

  1. 在飞书里把 AI 资讯 拉进目标群。
  2. 打开 群看板，点刷新。
  3. 每个群两个开关，互相独立：开通 = 群里 @ 才回答；早报 = 按设置里的时间发到该群，当天只发一次。

不必手填群 ID。私聊是总开关，在设置里，默认关。

5. 群里怎么问

只在已开通的群里，@ 机器人问今天、热点、日报、AA榜 / 模型榜 / 哪个模型最强、Tibo重置 / 重置预测 / Codex 额度 / 重置卡，或某个公司 / 模型。回复发在群里，不进话题。简报不写数据来自哪，标题链到原文。AA榜和 Tibo 重置发卡片，不走 Grok。没有未确认预告时，卡片会带官网同一套历史估计（仅供参考）。Tibo 新预告或确认完成时，也会推到已开通的群。

6. 边界

  • 只答 AI 资讯。不写代码、不闲聊、不调搜索。
  • 简报用的是你自己的 Grok 订阅额度。这个版本不按条收费；要对用户收费，先换成按量 API key。
  • 额度默认不限制，后台只统计今日调用。

7. 常见问题

@ 了没回
这个群还没开「开通」，或左边栏飞书 / Grok 不是绿灯。
看板没有群名
「获取群组信息」没发布。再发一版，然后刷新群。
私聊只提示
设置里「允许私聊」默认关。关掉时会回一句「请到已开通的群里 @ 我」，不走 Grok。
早报没收到
该群要单独开「早报」。同一天已发过的不会重发。时间在设置里改。
